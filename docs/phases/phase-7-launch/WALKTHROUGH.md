# Phase 7 walkthrough: evaluate and launch

## 1. What we built

| Part | What it does |
|---|---|
| Live answers | The API can call an internal **search service** (same image as the pipeline, no host port, shared key). Modes: local, relate, global, plain RAG, chosen by the router. Switch with `ANSWER_MODE=live` and `docker compose --profile live up -d --build` (CR-0004, D61) |
| Reliability | 4 questions at once, 5 s wait for a slot, 40 s deadline, retries on free reads, a circuit breaker around the model, 45 s limit and one connect-only retry on the API side, strict reply contract |
| Spending safety | Daily cost cap and per-visitor rate limits exercised with real calls: refused requests never reached the search service |
| Fixes | Refusal guards (plain-word names, unknown version numbers, plain-words refusals), a fix to the relate citation check, a router bug ("link prediction"), request logging |
| Final evaluation | One clean run, report generated by script: [EVALUATION.md](../../EVALUATION.md); reading in [EVALUATION_NOTES.md](EVALUATION_NOTES.md). Three targets missed, six met |
| Operations | `scripts/backup.sh`, `restore.sh`, `check.sh`; [RUNBOOK.md](../../RUNBOOK.md); restore tested into an empty stack, also from a fresh clone |
| Release pages | [README](../../../README.md), [ARCHITECTURE](../../ARCHITECTURE.md), [DEMO](../../DEMO.md), [INTERVIEW](../../INTERVIEW.md), [LIMITS](../../LIMITS.md) |
| CI | New checks in the `compose` job for the `live` profile and for the search service refusing to start without its keys |

## 2. How to see it yourself

1. `docker compose up -d --build`, open http://localhost:3000, click an example.
2. `bash scripts/check.sh` prints counts and `CHECK OK`.
3. Open [EVALUATION.md](../../EVALUATION.md) and compare with the README table.
4. Optional (costs about $0.003 per question): live mode as in the README.

## 3. What to remember

- Local search beats plain RAG on hard multi-hop questions by about 13 points here, but misses the
  75% target; it costs a third of a cent and takes about five seconds.
- The system refuses when it has no evidence, and checks its own citations.
- Three targets are missed on purpose-built honesty: nothing was tuned on the final sets except the
  refusal guards, which is said wherever the number appears.
- Spend in Phase 7: about $0.62 of the $3.00 cap, all asked and approved first.
